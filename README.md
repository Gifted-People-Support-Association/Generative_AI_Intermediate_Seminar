# 生成AI 中級編 ゼミ

## 📚 概要

本ゼミは、生成AIを各専門職の実務・制作・開発に接続するための土台となる知見を深める、中級者向けのハンズオン型プログラムです。

AIエージェントを活用したソフトウェア開発、デザインモックや議事録データの作成、Dify・n8n・Antigravity SDKを用いたAIシステム構築を通じて、生成AIを単なるチャットツールではなく、実務を支援する仕組みとして活用するきっかけを作ります。

また、Claude Code、Codex、Antigravityなどの発展的なAI開発ツールを扱い、ITエンジニア、デザイナー、事務職、データサイエンス領域での活用事例を確認します。加えて、ポートフォリオ制作に役立つGit / GitHubの基本的な使い方も扱います。

### 🎯 目的

単に「AIを使ってみる」段階から一歩進み、生成AIをどのように組み合わせ、設定し、目的に応じて活用すれば価値につながるのかを、実際に手を動かしながら知見を深めます。

生成AI関連のツールや仕組みを題材に、AIがどのように動き、どこに強みや限界があるのかを確認したうえで、現実の課題にどう応用できるかを考えます。講義だけでなくハンズオン形式の演習を通じて、試作を通じて活用の方向性を考えるきっかけを作ることを重視します。

### 👥 対象者

* 生成AIの基礎知識を持っている方（ChatGPTなどを使用した経験がある）
* 生成AIを実務やプロジェクトで活用したいと考えている方
* AIエージェントやAI開発支援ツールの基本的な使い方に触れてみたい方
* ITエンジニア、デザイナー、事務・バックオフィス、データサイエンスなどの専門領域での生成AI活用に関心がある方
* Git / GitHubを使った取り組み成果や制作物の管理について知見を深めたい方

### 🎓 このゼミで深める知見

本ゼミでは、以下の観点について知見を深めます。

1. **生成AIを業務・制作・開発に応用する考え方**
   - 生成AIの強み・制約を踏まえた活用場面の整理
   - ITエンジニア、デザイナー、事務職、データサイエンス領域での活用事例の確認
   - 実務課題に対するAI活用アイデアの検討

2. **AIエージェントの基本構造と使い方**
   - AIエージェントの自律性、ツール利用、推論ループの確認
   - AIエージェントを使ったソフトウェア開発の流れ
   - Claude Code、Codex、Antigravityなどの発展的ツールの活用イメージ

3. **ノーコード・ローコードによるAIシステムの試作**
   - Difyを使った生成AIアプリケーションの開発
   - n8nを使った業務自動化ワークフローの設計
   - Antigravity SDKなどを使ったAIシステム構築の基礎的なイメージ

4. **業務・制作データの作成と活用**
   - デザインモック作成への生成AI活用
   - 議事録、要約、整理済みデータなどの作成
   - データ分析や業務改善に向けた生成AI活用の入り口

5. **Git / GitHubを使った成果物管理の基礎**
   - Gitによる変更履歴管理の基本
   - GitHubを使った制作物・取り組み成果の公開準備
   - ポートフォリオ制作に必要な基本的な開発管理の流れ

## 転職・キャリア形成との関係

本ゼミでは、IT企業への転職時に作成するポートフォリオ制作に役立つGit / GitHubの基礎や、生成AIを基盤としたツールが各専門分野でどのように活用されているかを扱います。

ただし、本ゼミは転職を直接支援・保証する講座ではありません。受講によって転職が有利になることや、開発職・マーケティング職など特定の職種に就けるようになることは想定していません。

## 📖 カリキュラム構成

本ゼミは、生成AIを各専門領域へ応用するための土台として、以下の6つのテーマで構成されています。

### 1. 生成AI活用の基礎とAIエージェント概論

生成AIの基本的な活用方法から一歩進み、AIエージェントの仕組みや、ツールを使ってタスクを進める考え方に触れます。

| 回次 | テーマ | 主な確認内容 |
|------|--------|--------------|
| 第1回 | AIエージェント入門 | エージェントの自律性、ツール利用（RAG/検索/コード実行）、推論ループ |
| 第2回 | Agent Skills入門 | Skillsの概念、`SKILL.md`の構造、作成とテストの手順 |

### 2. AIエージェントを使ったソフトウェア開発

AIエージェントを開発補助として使い、要件整理、コード生成、修正、レビュー、テストの流れを体験します。

| テーマ | 主な確認内容 |
|--------|--------------|
| 開発支援AIツールの基礎 | Claude Code、Codex、Antigravityなどの特徴と使い分け |
| AIエージェントによる実装補助 | 要件整理、コード修正、テスト実行、レビュー補助 |
| 開発プロセスへの組み込み | AIの出力確認、制約の確認、人間による判断ポイント |

### 3. デザインモック・議事録・業務データ作成

生成AIを使い、専門職ごとの成果物作成や日常業務の効率化にどうつなげられるかを確認します。

| テーマ | 主な確認内容 |
|--------|--------------|
| デザインモック作成 | 画面案、構成案、文章案、画像生成の活用 |
| 議事録・要約作成 | 会議内容の整理、要点抽出、タスク化 |
| 業務データ作成 | 表形式データ、サンプルデータ、分析前処理の補助 |

### 4. Dify / n8n / Antigravity SDKを使ったAIシステム構築

ノーコード・ローコード・SDKを組み合わせ、生成AIを基盤とした簡易的なAIシステムを試作します。

#### Dify基礎（全5回・90分/回）

**Dify**は、プログラミング不要でAIアプリケーションを構築できるノーコードプラットフォームです。ビジュアルな操作で、RAGや外部API連携を含む高度なAIアプリケーションを開発できます。

| 回次 | テーマ | 主な確認内容 |
|------|--------|--------------|
| 第1回 | Dify導入と環境構築 | アカウント作成、モデルプロバイダー設定（Gemini）、基本操作 |
| 第2回 | LLMノードとプロンプト設計 | プロンプトエンジニアリング、モデルパラメータ調整、条件分岐 |
| 第3回 | Knowledge（RAG）導入 | ドキュメントアップロード、ナレッジベース構築、検索精度向上 |
| 第4回 | エージェントと外部連携 | HTTPノード、外部API連携、ワークフロー設計 |
| 第5回 | デプロイと発表 | 公開設定、運用、成果発表 |

**最終成果物例:**

- 社内FAQチャットボット（RAG活用）
- Google Sheets要約アシスタント（API連携）
- タスク自動化アシスタント

## 🛠️ 使用するツール・技術

### 必須・主要ツール

* **Dify**: AIアプリケーション開発プラットフォーム
  - Webブラウザ（Chrome/Edge推奨）
  - Difyアカウント（無料プランで開始可能）

* **Google AI Studio**: LLMモデルプロバイダー
  - Google Gemini API（無料枠あり）

* **Git / GitHub**: 成果物管理とポートフォリオ制作の基礎
  - Gitの基本操作
  - GitHubリポジトリの作成・管理

### 発展的に扱うツール

* **n8n**: 業務自動化ワークフロー構築
* **Antigravity SDK**: AIシステム構築の基礎
* **Claude Code**: AIエージェントを活用した開発支援
* **Codex**: AIエージェントを活用した開発支援
* **Antigravity**: 発展的なAI開発支援ツール

### 推奨環境

* **Node.js**: v18.0.0以上（LTS版推奨）
* **パッケージマネージャー**: pnpm
* **エディタ**: Visual Studio Code（推奨）
* **ブラウザ**: Chrome または Edge の最新版

## 🚀 セットアップ方法

### 1. リポジトリのクローン

```bash
git clone <repository-url>
cd generative-ai-intermediate
```

### 2. 依存関係のインストール

```bash
# pnpmを使用
pnpm install

# または npm
npm install
```

## 💡 取り組みのポイント

1. **実践重視**: 各セクションのハンズオンを必ず実施してください
2. **段階的な確認**: 各回の内容を順番に進めることを推奨します
3. **試行錯誤**: エラーやうまく動かない場合も、知見を深める機会として捉えてください
4. **成果物の作成**: 最終的に自分の課題を解決するアプリケーションや制作物を作成してください
5. **人間による確認**: AIの出力はそのまま採用せず、目的・品質・安全性を確認してください
